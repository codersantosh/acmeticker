AcmeTicker

A zero-dependency vanilla JS news ticker with vertical, horizontal, marquee and typewriter modes, full RTL support, and a jQuery-free successor to the v1 plugin.

Quick start

npm install acmeticker
<script src="https://cdn.jsdelivr.net/npm/acmeticker@2.0.0/dist/acmeticker.min.js"></script>
<script>
  new AcmeTicker(document.querySelector('.my-news-ticker'), { type: 'horizontal' });
</script>
