Features

Everything a news ticker needs

Built for publishers and developers who want a ticker that just works - styled by you, driven by AcmeTicker.

Zero dependencies

Vanilla JavaScript only. No jQuery, no framework - just new AcmeTicker(el, options).

Four engines

Vertical, horizontal, marquee and typewriter modes, switchable at runtime with update().

Full RTL support

Automatic mirroring on Arabic and Hebrew pages. Logical left/right directions.

TypeScript types

Full type declarations shipped with the package. Works under NodeNext and bundler resolution.

Accessible by default

Pauses on hover and focus, respects prefers-reduced-motion, aria-live aware.

RAF animations

Buttery 60fps transitions with v1-parity easing. autoplay: 0 loops seamlessly.

Events & controls

acmeTickerCycle and acmeTickerToggle events, selector or element controls.

Any build setup

ESM, CommonJS and a global script build. Use it with bundlers, script tags or React.

RTL support

Arabic and Hebrew, out of the box

Point AcmeTicker at a dir="rtl" page and everything mirrors automatically - motion, entry side and rest position.

Logical directions, zero configuration

  • Automatic detection from dir="rtl", dir="auto" or CSS direction.
  • direction: 'left' | 'right' stays logical in both languages.
  • Force or disable with the rtl option - rtl: false keeps physical motion.
  • Vertical and typewriter modes are direction-neutral and unaffected.
<html lang="ar" dir="rtl">
  <ul class="my-news-ticker">...</ul>
</html>

new AcmeTicker('.my-news-ticker', {
  type: 'horizontal'
});

Quick start

Up and running in minutes

Four ways to add a ticker. Pick your setup.

Install 
npm install acmeticker
Plain script tag 
<script src="https://cdn.jsdelivr.net/npm/acmeticker@2.0.0/dist/acmeticker.min.js"></script>
<script>
  new AcmeTicker(document.querySelector('.my-news-ticker'), {
    type: 'horizontal',
    direction: 'right'
  });
</script>
Vanilla / bundlers 
import { AcmeTicker } from 'acmeticker';

const ticker = new AcmeTicker(document.querySelector('ul.ticker'), {
  type: 'vertical',
  direction: 'up',
  speed: 600,
  autoplay: 4000,
  pauseOnHover: true,
  controls: {
    prev: '.at-ticker-prev',
    next: '.at-ticker-next',
    toggle: '.at-ticker-pause'
  }
});
React 
import { useEffect, useRef } from 'react';
import { AcmeTicker } from 'acmeticker';

function Ticker({ items }) {
  const listRef = useRef(null);

  useEffect(() => {
    const ticker = new AcmeTicker(listRef.current, {
      type: 'marquee'
    });
    return () => ticker.destroy();
  }, []);

  return (
    <ul ref={listRef}>
      {items.map((item) => <li key={item}>{item}</li>)}
    </ul>
  );
}

Options and methods

The complete public surface - small on purpose.

OptionDefaultDescription
type'horizontal'vertical, horizontal, marquee or typewriter
autoplay2000Pause between transitions (0 = continuous loop)
speed50Transition duration, char delay or marquee px/ms
direction'up'up / down / left / right - logical under RTL
rtl'auto'auto-detect, or force true / false
pauseOnFocustruePause while the ticker region is focused
pauseOnHovertruePause while the pointer is over the ticker
controls{}prev / next / toggle - selectors, elements or NodeLists
play() resume pause() freeze toggle() flip next() / prev() navigate update() re-configure destroy() teardown
